# Plant Directory Utility

A lightweight Python script built to practice core programming concepts like dictionaries, functions, and conditional logic to organize biological data.

## Features
* Stores plant species information using Python dictionaries.
* Allows users to search for scientific names, family classifications, and watering requirements.

## How to Run
```bash
python plant_directory.py
