# 🌿 Plant Directory Utility

A beginner-friendly Python project for searching, viewing, and adding plant information. Plant data is stored locally in a JSON file.

## Features

- 🔍 Search for a plant by its common name
- 📚 Display all plants in the directory
- 🌱 Add new plants with their scientific names and families
- 💾 Save plant information using JSON
- 🔄 Load saved plant data when the program starts

## Technologies Used

- Python 3
- JSON
- pathlib

## Project Files

- `plant_directory.py` — Main Python application
- `plants.json` — Sample plant database

## How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Keep `plant_directory.py` and `plants.json` in the same folder.
4. Open a terminal in that folder.
5. Run:

   ```bash
   python plant_directory.py
   ```
